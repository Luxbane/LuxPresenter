Microsoft Edge WebView2 Runtime (Fixed Version, online browser engine)
========================================================================

The Online browser needs the Microsoft Edge WebView2 Runtime. So that the Portable package works without installing
anything, the Fixed Version Runtime is included in "Engines\WebView2".

  Package  : Microsoft.WebView2.FixedVersionRuntime.157.0.4341.60.x64.cab, downloaded from the link Microsoft
             publishes on https://developer.microsoft.com/microsoft-edge/webview2/ (Fixed Version, x64)
  SHA-256  : 1bad3df802a4c21f6b271cf3cd640912056291e3915b86fa7577a18899f761b9
             (the CAB is Authenticode-signed by Microsoft Corporation; signature verified). Extracted files unmodified.
  Method   : expand.exe of the CAB into Engines\WebView2\157.0.4341.60\

Redistribution: Microsoft documents the Fixed Version distribution mode (docs "Distribute your app and the WebView2
Runtime"): the binaries are included in the application package and their folder is passed to the WebView2 environment
as the browser executable folder, which LuxPresenter does. The runtime is governed by the Microsoft Edge WebView2
Runtime licence terms and includes third-party software; its notices are listed by
Engines\WebView2\157.0.4341.60\show_third_party_software_licenses.bat.

LuxPresenter uses the folder first and falls back to the registered (Evergreen) runtime if the bundled one cannot be
started. The fixed runtime is not updated automatically; replace the folder with a newer Fixed Version package to
update it.
