LibreOffice (presentation conversion engine)
============================================

LuxPresenter converts PowerPoint / OpenDocument presentations to PDF with its own copy of LibreOffice, which lives
in the "Engines\LibreOffice" folder of the Portable package. It runs only as a hidden background process
(soffice --headless --convert-to pdf); it is never used to show anything to the audience.

  Product  : LibreOffice 26.8.3 (x86-64), The Document Foundation
  Package  : LibreOffice_26.8.3_Win_x86-64.msi, the official release installer
             https://download.documentfoundation.org/libreoffice/stable/26.8.3/win/x86_64/
  SHA-256  : 0e6918c273eabbdbbd800ee0dacbbf130a14c13c2e4cec861b06dd59e015bf94 (matches the published checksum;
             the installer is Authenticode-signed by The Document Foundation)
  Method   : "msiexec /a" administrative extraction of that MSI (no installation, no registry entries). The files are
             not modified. The only additions are Microsoft's redistributable Visual C++ runtime DLLs (vcruntime140,
             vcruntime140_1, msvcp140, msvcp140_1, msvcp140_2) placed next to the LibreOffice program files, because the
             official installer relies on a system-wide runtime that a portable copy cannot assume. The installer file
             itself is not shipped.
